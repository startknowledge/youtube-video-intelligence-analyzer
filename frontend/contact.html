Contact Us

We welcome questions, bug reports, suggestions, and feedback about YouTube Video Intelligence Analyzer. The fastest way to receive useful help is to clearly describe what you were trying to do, what happened, and what result you expected.

Technical support

If an analysis fails, include the general error message, the affected feature, and the time the issue occurred. Do not send API keys, passwords, cookies, authentication tokens, or private credentials. If the problem is related to a particular public YouTube video, you may include its public URL.

Feature requests

Useful feature requests include transcript support, better keyword grouping, improved chapter detection, stronger SEO explanations, export formats, accessibility improvements, and creator workflow enhancements. Explain the problem the feature would solve rather than only naming the feature.

Bug reports

A good bug report contains the browser and device type, the page used, the steps that caused the problem, the visible error, and whether the issue happens consistently. Screenshots can be helpful when they do not expose personal or confidential information.

Privacy requests

For privacy questions, access requests, correction requests, deletion requests, or other data-related concerns, identify the request clearly. We may need reasonable information to verify that the request relates to you.

General information

For general questions about the analyzer, start with the FAQ and Documentation pages. They describe supported inputs, expected results, limitations, and common troubleshooting steps.

Response expectations

Support response time can vary depending on the type of request, technical complexity, service availability, and workload. A support message does not guarantee that a requested feature will be implemented.

Responsible communication

Please do not use contact channels to send spam, malicious files, credentials, abusive content, or automated traffic. Messages that contain security-sensitive information should be handled carefully and should never include secrets in plain text.

Before contacting support

Check that the YouTube URL is valid, the video is accessible, your browser has a working internet connection, and any required application permissions are available. If transcript analysis is unavailable, the video may not have an accessible transcript or the current transcript method may not support it.

What to send

  • The page or feature you used.
  • A short description of the issue.
  • The exact error text, if any.
  • The public video URL, when relevant.
  • Browser and operating system information, when relevant.
  • A screenshot with private information removed, when useful.

We appreciate constructive feedback and use it to improve reliability, clarity, and usability.
